# ZYG — Shitcoins

[Играть](https://azkian1.github.io/zyg-shitcoins/)

Отбивай Shitcoins, чтобы не набирать их в портфель.
Мелкие круглые монеты — руками, крупные с красным свечением — ногами.

| Приём | Влево | Вправо |
| --- | --- | --- |
| Кулак | Q | I |
| Нога | W | O |
| Ладони | E | P |
| Удар в прыжке | Shift + W | Shift + O |

Пробел — брейк. Esc — пауза. M — звук.
На телефоне используй экранные кнопки.

Статическая игра без установки и внешних зависимостей.
